# Jessnix Browser

A fast, private Chromium-based browser for daily use.

Built as a patch set on top of [ungoogled-chromium](https://github.com/ungoogled-software/ungoogled-chromium), the way [LibreWolf](https://librewolf.net/) builds on Firefox: upstream engine, no telemetry, privacy defaults, bundled ad blocking, and a few features of its own.

**Status:** planning. See [PLAN.md](PLAN.md) for the roadmap.

## Layout

| Folder | Contents |
|---|---|
| `branding/` | App icons |
| `patches/` | Jessnix patches applied on top of ungoogled-chromium |
| `config/` | Build flags, first-run preferences, policies |
| `scripts/` | Fetch, patch, build and package scripts |
| `docs/` | Feature notes and the Chromium update guide |
